# Introduction to Algorithms

Open [TODAY.md](TODAY.md), do that one task, and stop. It is one Python problem. After the first three problems, watch the [Python graph showcase](https://start.interviewing.io/showcase/hJ717oe4XhaB) for 25 minutes. Chapter replays are listed under When the book arrives in [study/STUDY.org](study/STUDY.org).

- [TODAY.md](TODAY.md) is the one task for the session. [practice/](practice/) holds the problem list, the log, and the Python file for the current problem.
- [study/](study/) holds the study plan, the [task list](study/tasks/todo.md), and the local course dump in `study/6.006-spring-2020/`. That dump is gitignored.
- [docs/](docs/) is the study tracker published with GitHub Pages.
- [cpp/](cpp/) holds the C++ exercises. The active project is [DSA-Project](cpp/DSA-Project/). Earlier exercises are in `cpp/completed-projects/`, `cpp/Matrices/`, and `cpp/MatricesCPP/`.

Build steps and the `Array<T>` feature list are in the [DSA-Project readme](cpp/DSA-Project/README.md).
